3Blue1Brown × Jane Street puzzle

How long until Andy the Ant gets home?

An ant wanders at random over the patches of a soccer ball. Starting on a pentagon, how many moves does it take, on average, to step back onto that same pentagon?

36 expected moves to return to the starting pentagon

The problem

A soccer ball is a truncated icosahedron. It has 20 white hexagons and 12 coloured pentagons. Each hexagon borders 3 hexagons and 3 pentagons, alternating around its edge. Each pentagon borders 5 hexagons and no other pentagons.

Andy the Ant starts on a pentagon. On each move he steps to one of the bordering patches, chosen uniformly at random. He is allowed to step straight back to where he came from. We want the expected number of moves until he first lands back on his starting pentagon.

20 hexagons, degree 6 11 other pentagons, degree 5 1 starting pentagon, degree 5

An interactive model of the ball, with the starting pentagon in red, is here. Drag it around to check the adjacencies below.

The approach

A random walk on 32 patches is a Markov chain with 32 states. That is small enough to solve directly, but symmetry makes it much smaller. The ball looks the same under any rotation that fixes the starting pentagon, so every patch that is the same "distance and type" from the start behaves identically. That collapses the 32 patches into 8 classes.

The eight classes

Think of the ball as an icosahedron: pentagons sit at its 12 vertices and hexagons sit on its 20 faces. Put the starting pentagon at the north pole. The remaining pentagons form an upper ring of 5, a lower ring of 5, and the south pole. The hexagons form four bands of 5.

First-step equations

Let \(t_X\) be the expected number of moves from a patch in class \(X\) until Andy reaches P0. Every move costs 1, and then Andy is in a new class, so each \(t_X\) is one plus the average of its neighbours' values. A step onto P0 ends the walk and contributes 0.

\[ \begin{aligned} t_{H1} &= 1 + \tfrac13 t_{H1} + \tfrac13 t_{P2} + \tfrac16 t_{H2} \\ t_{P2} &= 1 + \tfrac25 t_{H1} + \tfrac25 t_{H2} + \tfrac15 t_{H3} \\ t_{H2} &= 1 + \tfrac16 t_{H1} + \tfrac13 t_{P2} + \tfrac13 t_{H3} + \tfrac16 t_{P3} \\ t_{P3} &= 1 + \tfrac15 t_{H2} + \tfrac25 t_{H3} + \tfrac25 t_{H4} \\ t_{H3} &= 1 + \tfrac16 t_{P2} + \tfrac13 t_{H2} + \tfrac13 t_{P3} + \tfrac16 t_{H4} \\ t_{H4} &= 1 + \tfrac16 t_{H3} + \tfrac13 t_{P3} + \tfrac13 t_{H4} + \tfrac16 t_{P5} \\ t_{P5} &= 1 + t_{H4} \end{aligned} \]

Andy's first move from P0 always lands on an H1 hexagon, so the answer is

\[ \mathbb{E}[\text{return}] = 1 + t_{H1}. \]
The \(\tfrac16 t_{H1}\) that would appear in the H1 row for stepping onto P0 is deliberately missing. That step absorbs, so its contribution is 0, not \(t_{P0}\).

Solving it as an absorbing chain

Write the seven transient classes in the order H1, P2, H2, P3, H3, H4, P5 and let \(Q\) hold the move probabilities between them. The seven equations above are exactly

\[ (I - Q)\,\mathbf{t} = \mathbf{1}. \]

\(I - Q\) keeps 1 minus each diagonal entry and negates everything off the diagonal.

The fundamental matrix

Inverting gives the fundamental matrix \(N = (I - Q)^{-1}\). Entry \(N_{ij}\) is the expected number of visits to class \(j\) before absorption, starting from class \(i\). Summing a row gives that class's expected moves to P0.

The H1 row is the one that matters. It sums to \(t_{H1} = 35\), so

\[ \mathbb{E}[\text{return}] = 1 + 35 = 36. \]

Why the H1 row is so clean

Every other row of \(N\) is a mess of fractions, but the H1 row is small integers. That is not luck. Starting from H1 is the same as watching one excursion from P0, and for a random walk on a graph the expected number of visits to a vertex \(v\) during one excursion from \(u\) is \(\deg(v)/\deg(u)\).

With \(\deg(u) = 5\), each hexagon is visited \(6/5\) times per excursion and each other pentagon exactly once. Multiply by the class sizes and the H1 row appears: five hexagons give 6, five pentagons give 5, and the lone antipodal pentagon gives 1.

The one-line answer

The same fact gives the answer without any matrix. For a random walk on a connected graph, the expected return time to a vertex is

\[ \mathbb{E}[\text{return to } u] = \frac{2|E|}{\deg(u)}. \]

The ball has 90 borders between patches, so \(2|E| = 180\). A pentagon has degree 5, and \(180 / 5 = 36\). The Markov chain and the degree formula agree.

The same formula says a walk starting on a hexagon returns in \(180/6 = 30\) moves on average.

Checking by computer

The whole solve is a few lines of numpy. The exact fractions above come from repeating it with Python's fractions module.

import numpy as np

Q = np.array([
    [1/3, 1/3, 1/6, 0,   0,   0,   0  ],   # H1
    [2/5, 0,   2/5, 0,   1/5, 0,   0  ],   # P2
    [1/6, 1/3, 0,   1/6, 1/3, 0,   0  ],   # H2
    [0,   0,   1/5, 0,   2/5, 2/5, 0  ],   # P3
    [0,   1/6, 1/3, 1/3, 0,   1/6, 0  ],   # H3
    [0,   0,   0,   1/3, 1/6, 1/3, 1/6],   # H4
    [0,   0,   0,   0,   0,   1,   0  ],   # P5
])
t = np.linalg.solve(np.eye(7) - Q, np.ones(7))
print(1 + t[0])   # 36.0
